## 批一 · 视觉语言统一

- [ ] 扫光动画为全局唯一「进行中」视觉：深度思考标题（流式中）、工具卡执行中 label、底部状态行三处共用同一 CSS 工具类，2.2s 线性无限，完成态回归静态灰字
- [ ] 深度思考块：流式默认展开，assistant_done 后自动收起；用户手动干预后不再自动开合；展开态 200px 限高 + 左侧竖条 + 渐隐
- [ ] 等待首响应 4s 后出现 tips，10s 轮换不重复，hover 暂停，× 关闭当条会话内不再出现；tips 文案为自创（grep 比对无 WorkBuddy 原文）
- [ ] 等待 8s 未响应时状态行切换安抚文案（自创）
- [ ] 用户中断后：消息流出现「用户已取消」指示行；TurnHeader 定格「已取消 Ns」而非「已完成」；reducer 有对应测试
- [ ] 中文输入法选词按 Enter 不发送；compositionend 后 100ms 内 Enter 被吞；守卫逻辑有单测

## 批二 · 消息流结构

- [ ] 已完成回合的连续工具卡折叠为一行摘要（动作词归类计数或「N 个工具调用」兜底），点击展开/收起，进行中回合不折叠；分组与摘要有单测
- [ ] 用户消息为右侧气泡（圆角 16/16/0/16）；hover 浮现时间戳（四档格式有单测）+ 复制（对勾 2s）
- [ ] 用户上滚后新内容不强制贴底；「回到底部」按钮浮现；点击或滚回底部恢复跟随
- [ ] run_error 显示内嵌错误卡（message + runId + 结构化复制 + 重试）；重试重发最后一条 user 消息

## 批三 · 输入区补齐

- [ ] 停止需二次确认：首次点击/Esc 后按钮变 Esc 徽章，3s 内再确认才中断，超时复原；状态机有单测
- [ ] Alt+↑/↓ 翻输入历史；回到最新再按 Alt+↓ 恢复翻前草稿
- [ ] 切换视图（chat↔home↔settings）后输入草稿按 sessionId 还原
- [ ] 输入超 10 万字符无法继续输入；剩余 <1000 显示余量，超限变红禁发
- [ ] 非 craft 模式时输入区显示模式 chip，hover 变 ×，点击回落 craft
