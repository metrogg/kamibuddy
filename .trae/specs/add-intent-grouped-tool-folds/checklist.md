# Checklist

## 分组

- [x] 连续 ≥2 个可折叠单元（工具调用、纯思考）被收成一个组；**正文是唯一断组边界**
- [x] 缓冲内**恰好 1 个**可折叠单元时不构成组（按单条平铺，无组头）
- [x] 组内允许混合不同工具
- [x] 豁免卡（`show_widget` / `todo_write` 等既有豁免）不参与成组且位置不变
- [x] 用户消息终止当前组（轮边界）
- [x] **分组在顶层渲染路径也生效**（进行中的轮同样成组，不再只在折叠段内）

## 组头文案

- [x] 组头是**意图标题**（含主题），不是「读取 2 个文件」这类类型计数
- [x] 单工具标题形如「查看 README.md」
- [x] 同类别多工具标题形如「定位 *.py 相关代码」
- [x] 跨类别多工具标题形如「定位代码、运行校验：<主题>」
- [x] 主题来源优先级：工具入参对象字段 → 相邻正文关键词 → 无
- [x] 取不到主题时只显示动词，**无悬空冒号/分隔符**
- [x] 运行中的组带「正在」前缀
- [x] 主题值做压缩（路径取 basename；超长按中文/英文规则截断）
- [x] 组头带主导工具的图标（复用既有 `FOLD_LEAD_ICONS`）
- [x] 主题字段口径与 `session-host.ts` 的 `summarizeArgs` **同源**（未各写一套）

## 折叠时机

- [x] `shouldFold = 其后出现过正文 || 整轮已结束`
- [x] **正在执行的尾批保持平铺**（不渲染组头）
- [x] 默认态为收起
- [x] 手动展开在该组生命周期内不被流式刷新重置；进入新轮重置为收起
- [x] 组 id 稳定（不含易变下标），流式刷新不丢手动展开态

## 与既有机制的关系

- [x] 轮折叠（`turn-folded` / `process-fold`）语义**未变**
- [x] 轮折叠与工具组折叠**两层共存**（轮折叠 > 工具组），共用同一个折叠外壳
- [x] **未新建折叠层**（复用 `SegmentFold` / `foldOpen` state / `groupToolBatches` 骨架）

## 交互与性能

- [x] 点击组头展开时**释放吸底跟随**（展开内容向下增长，组头位置稳定）
- [x] 既有折叠头（轮折叠、过程消息）的同类行为未被误伤
- [x] 对话主渲染路径**未引入新的每帧重建**（分组纯函数的 memo 策略到位）
