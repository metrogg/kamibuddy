# 右侧面板视图层级修正（概览/工作空间文件/变更 平级）Spec

## Why

WorkBuddy 5.5.4 实测截图（用户提供的三张）：右侧面板头部下拉是**视图切换器**——
概览 / 工作空间文件 / 变更三者**平级**（菜单内带 ✓ 标记当前视图）；
产物是「概览」视图内的下一级分组。KamiBuddy 现实现把 产物/变更/工作区文件
三组全塞进「概览」一个下拉菜单里，层级错误：变更与工作区文件被错误地降为概览的子级。

## What Changes

**A. 头部下拉改为视图切换器**
- 按钮文案 = 当前视图名（概览/工作空间文件/变更）+ chevron（WorkBuddy 同款）
- 菜单项 = 三个平级视图，当前视图带 ✓（不再内嵌任何文件列表）
- 选中即切换到对应视图

**B. 三个平级视图的内容**
- **概览**：产物折叠组（计数、空态「暂无内容」、单击预览/双击转正/URL 外部打开——
  沿用现有条目行为）
- **变更**：顶部汇总头「文件变更 +N -M」（全变更增删行合计，WorkBuddy 截图 3 同款）
  + 变更列表（文件名 + +/- 徽章，行为沿用）
- **工作空间文件**：现有懒加载目录树（复用 workspace-file-tree，行为不变；
  无工作区时占位沿用）

**C. 面板主体双态（列表态 / 预览态）**
- 列表态：主体显示当前视图内容（默认 = 概览）
- 点击任一条目 → 预览态（现有 tabs + 预览渲染，pick/pin 语义不变）
- 预览态下操作视图切换器 → 回到列表态对应视图；tabs 保留在 tab 条上，
  点 tab 即回预览态
- 关闭最后一个 tab → 自动回到列表态（保持当前视图）
- 空态语义不变：无产物时概览显示「暂无内容」；无预览时不再是
  「选择文件以预览」占位——列表态本身就是默认内容

**D. 删除旧结构**
- OverviewMenu 的「一个下拉内嵌 产物/变更/工作区文件 三组」整体移除，无兼容壳

## Impact

- Affected specs：产物预览面板（upgrade-preview-panel-and-cards、
  upgrade-preview-panel-workspace-files、fix-panel-bubble-history 的后续修正）
- Affected code：
  - `src/renderer/artifact-panel.tsx`（OverviewMenu 区域重构为视图切换器 + 三视图 + 双态主体）
  - `src/renderer/index.css`（切换器菜单/✓/变更汇总头/视图内容区样式）
  - 新增 `src/renderer/panel-view.ts`（视图与主体双态的纯状态机）+ 测试
- 无 IPC / shared / daemon 变更

## ADDED Requirements

### Requirement: 视图切换器

系统 SHALL 在面板头部提供视图切换器：按钮显示当前视图名，
菜单列 概览/工作空间文件/变更 三个平级项，当前项带 ✓；选中即切换。

#### Scenario: 切换视图
- **WHEN** 用户在预览态或列表态点击切换器并选「变更」
- **THEN** 面板主体显示变更视图（汇总头 + 变更列表），切换器按钮文案变为「变更」

### Requirement: 三个平级视图

系统 SHALL 提供三个平级视图：概览（产物折叠组）、变更（「文件变更 +N -M」
汇总头 + 变更列表）、工作空间文件（目录树）。产物只属于概览视图，
不再与变更/工作空间文件同列于一个菜单。

#### Scenario: 概览视图内容
- **WHEN** 会话已交付 2 个产物，用户位于概览视图
- **THEN** 显示「产物」折叠组含 2 个条目；无产物时显示「暂无内容」

#### Scenario: 变更视图汇总头
- **WHEN** 会话有 3 处变更（合计 +500 -12），用户切到变更视图
- **THEN** 顶部显示「文件变更 +500 -12」，下方 3 个变更条目各带 +/- 徽章

### Requirement: 列表态与预览态

系统 SHALL 让面板主体在列表态（当前视图内容）与预览态（tabs + 预览）间切换：
点条目进预览态；预览态切视图回列表态（tabs 保留可点回）；关最后一个 tab 回列表态。

#### Scenario: 条目进预览、切视图回列表
- **WHEN** 用户在概览点击某产物（进预览态），再点切换器选「工作空间文件」
- **THEN** 主体显示目录树；tab 条上该产物 tab 保留，点击可回预览态

#### Scenario: 关闭全部 tab
- **WHEN** 用户关闭最后一个预览 tab
- **THEN** 主体回到列表态，显示切换器当前所选视图

## MODIFIED Requirements

### Requirement: 面板空态

**原**：无激活预览时主体显示「选择文件以预览」占位，概览下拉内嵌三组导航。
**新**：默认即列表态（概览视图），空产物组显示「暂无内容」；
「选择文件以预览」占位不再作为默认主体。

## REMOVED Requirements

### Requirement: 概览下拉内嵌三组导航

**Reason**：层级错误——变更/工作空间文件被降为概览子级，与 WorkBuddy 实际结构
（三者平级视图切换）不符。
**Migration**：OverviewMenu 整体重构为视图切换器 + 三视图；条目点击行为
（pick/pin/外部打开）逐条沿用，无交互回归。
