# Checklist

## 分组归属

- [x] playground 会话只出现在「任务」区；工作空间会话只出现在「空间」区对应组下，互不串区
- [x] 同一 cwd 的多个会话归在同一个空间组下
- [x] 任务区按修改时间倒序，>5 条时显示前 5 条 +「查看更多 (N)」，点击展开全部
- [x] 空间组间按组内最近任务时间倒序，组内任务按修改时间倒序

## 折叠与新建

- [x] 空间组头有折叠箭头，点击折叠/展开组内任务
- [x] 组头「+」点击后：首页工作空间 chip 切到该空间，且处于新任务状态（该空间下发消息即在其下开新会话）

## 空间菜单

- [x] 「⋯」菜单含：打开文件夹 / 重命名 / 从列表移除
- [x] 打开文件夹：系统文件管理器打开该空间目录；非法路径（非已知空间）被 daemon 拒绝
- [x] 重命名：组头显示新名，磁盘目录名不变，重启后仍在；空名/非法字符/超长/重名/保留名给出对应错误
- [x] 从列表移除：行内二次确认 → 组消失，该 cwd 全部会话文件进 `~/.kamibuddy/trash/`；当前任务所在空间移除被拒并提示先新建任务

## 任务状态指示

- [x] 当前会话流式中时，其所在行显示转圈
- [x] 任务在后台完成（用户不在对话页查看它）→ 该行出现绿点；点击该任务后绿点消失

## 与既有功能兼容

- [x] 任务行的恢复/导出/重命名/删除在任务区与空间组内都正常
- [x] 新建任务按钮行为不变；工作空间切换（首页 picker）行为不变

## 工程验证

- [x] `npm run check`（typecheck + check:deps）通过
- [x] `npm test` 全绿（含 workspace-registry 与 session-groups 新增用例）
- [x] `npm run smoke:session` 与 `npm run smoke:permission` 不回退
- [x] docs/STATUS.md 有「侧栏任务×空间重构」小节与待验证项
