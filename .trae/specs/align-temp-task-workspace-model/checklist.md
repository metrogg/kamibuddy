# Checklist

## 临时任务默认落点

- [ ] 不动工作空间选择直接发消息：会话 cwd = `~/KamiBuddy/临时任务`（目录自动创建），可让 AI 在该目录读写文件（权限门按工作区放行）
- [ ] 临时任务可加载完整工具集（read/write/edit/ls 等）且权限门生效：写临时目录外文件弹审批、读 .ssh 被拒
- [ ] picker 不再有「不使用工作空间」选项；首页工作空间 chip 默认显示「临时任务」
- [ ] 预览服务对临时任务可用（产物可预览）

## 默认存储路径设置

- [ ] 设置页「默认存储路径」区块显示当前生效根；可经目录选择对话框修改；可还原默认
- [ ] 修改后新任务落在新根的「临时任务」下；已有会话 cwd 不变
- [ ] env KAMIBUDDY_WORKSPACE_DIR > 设置项 > 内置默认 的分层正确；设置非法路径回退内置默认

## 保存到工作空间

- [ ] 临时任务的对话页头部有「保存到工作空间」按钮；非临时任务不显示
- [ ] 输入名称 → 创建 `<根>/<名称>/` → 会话以新 cwd 继续（历史完整）→ 空间区出现该组且任务归入
- [ ] 空名/非法字符/超长/重名/保留名给出对应错误；流式中按钮不可用或被拒
- [ ] 临时目录里已有文件保持不动；之后的产物写入新目录

## 分组与旧会话归类

- [ ] 临时任务（含 cwd=默认根本身的会话）出现在任务区；命名空间会话在空间区
- [ ] 变更前的旧 playground 会话（cwd=configDir/playground）：列表中显示在任务区；恢复后以临时任务身份继续（cwd 为临时目录）
- [ ] 空间区不出现「临时任务」组与「默认根」组

## 契约与背书

- [ ] 全仓无 isPlayground 残留（代码/测试/smoke 脚本），统一为 isTempTask
- [ ] session-events.ts 等处「WorkBuddy cwd=\"\" 同语义」错误背书已删除

## 工程验证

- [ ] `npm run check`（typecheck + check:deps）通过
- [ ] `npm test` 全绿（preferences 分层/临时判定/分组改名等新增与同步用例）
- [ ] `npm run smoke:session` 与 `npm run smoke:permission` 不回退（playground 断言已同步）
- [ ] docs/STATUS.md 有「临时任务模型对齐 WorkBuddy」小节（含错误背书更正）；旧 playground 章节标记废弃
