# diagram 模块：流程图 / 结构图 / 示意图（SVG）

先分流，再动手：

| 内容 | 路线 |
| --- | --- |
| 步骤、审批、数据/请求流向 | 流程图（本模块，SVG） |
| 组织架构、系统组成、层级包含 | 结构图（本模块，SVG） |
| 概念类比、机制示意、点缀插画 | 示意图（本模块，SVG） |
| 数据统计（柱/线/饼/条） | **不是本模块**——走 chart 模块的 Chart.js |

三类图都遵守 svg-setup 模块的 680 管线、safe area 与预置 class，下面只写各自的排版规则。

## 流程图

- **流向**一律从左到右或从上到下，一幅图只选一个主方向；箭头只出现在流向末端。
- **节点同高**：同一幅图所有节点统一高度——单行文字 40px、需要两行文字时 56px，同图只选一档，不要单行 40 与双行 56 混排。
- **节点间距**：水平相邻节点间隔 ≥32px，垂直相邻 ≥40px；分支/汇合处再放宽半档，避免箭头挤在一起。
- **节点数上限**：单图不超过 10 个节点。超出时先合并步骤或拆成两幅图，不要缩字号、缩间距硬塞。
- 分支条件写在连线上（`ts` 小字），不要塞进节点里。
- **循环流程例外**：不画首尾相接的环——回绕箭头在 680 宽的坐标系里必然穿过其他节点，又乱又难排。改用 HTML stepper 表达：一行有序步骤条（带序号的圆点 + 标题，步骤间用分隔线连接），末尾加一句"完成后回到第 1 步循环"的文字标注即可。

## 结构图

- **嵌套层数**：容器套容器不超过 2–3 层；层级再深就拆图，或改成交替缩进的文字列表。
- **圆角**：最外层容器 20–24px，内层元素 10–12px——外圆内方，层次靠圆角差区分。
- 父子关系优先用"包含"表达（父容器内边距 ≥16px，子块整齐排列其中），少用引线；只有跨容器的关联才画 `leader` 引导线。
- 同级容器同宽同高、间距一致（≥16px），用网格对齐，不要手工漂移。

## 示意图 / 插画

- **颜色编码强度**：同一语义同一色，全图不超过 4 个色系；装饰元素一律灰色系，语义色只留给要表达的含义。
- **允许轻动画**：只动 `transform` 与 `opacity`（CSS animation 或 SMIL 均可），单轮时长 ≤2s，可无限循环；禁止对宽、高、top、left 等布局属性做动画——会触发重排，干扰卡片高度自适应。
- 示意图也要有信息密度：每个图形元素都应该对应讲解里的一个概念，不画纯装饰场景。

## 通用提醒

- 所有文字用 `t` / `ts` / `th` 预置 class；节点、容器用 `box` / `node`；连线用 `arr` / `leader`。
- 提交前按 svg-setup 末尾的自检清单过一遍：680 管线、safe area、单 svg、连线 fill="none"。
