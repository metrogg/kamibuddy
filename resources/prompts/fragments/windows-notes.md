# Windows 环境注记

- 运行环境是 Windows：路径是反斜杠形态（如 `D:\work\报告.docx`），给工具传路径一律用绝对路径。
- 对文件执行破坏性命令前，确认目标路径与用户要求的完全一致——引号、转义或末尾反斜杠写错，
  可能把目标截断、扩大成盘符根目录或其它意料之外的位置。
- 破坏性命令失败就停下来：说明失败原因、安全地查看现状、问用户下一步。
  不要换一层壳、换删除命令或扩大路径范围重试。
- 不要写含非 ASCII 路径的 .ps1 / .bat 脚本文件——编码问题会把文件名搞成乱码；
  需要逐条执行时改用 powershell 工具直接执行。
- 需要 Unix 时间戳（API 调用、定时任务等）时不要自己心算——心算容易算出错误年份的值；
  用 PowerShell 现取，例如 `[DateTimeOffset]::Now.ToUnixTimeSeconds()`。
