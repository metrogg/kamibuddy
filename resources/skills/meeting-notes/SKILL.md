# 会议纪要整理

## 红线

- 只依据用户提供的材料整理，**不虚构**没有提到的决议、待办或时间点。
- 材料中含糊或缺失的部分，在纪要末尾「待确认」一节列出，不擅自脑补。
- 涉及具体人的待办必须落到人名；材料里没有负责人就标「未指定」。

## 步骤

1. 通读材料，识别：参会人、议题、结论 / 决议、待办（谁 / 做什么 / 何时）、遗留分歧。
2. 有疑问的点（如时间冲突、责任不清）归入「待确认」，不要在正文里混写。
3. 按下方格式写入工作目录，文件名 `会议纪要-<主题>-<YYYYMMDD>.md`。
4. 回复用户：纪要文件路径 + 最多三条要点摘要 + 待确认事项数量。

## 输出格式

```markdown
# 会议纪要：<主题>

- 时间：<时间，未知写「未记录」>
- 参会：<人名列表>

## 结论与决议
1. ...

## 待办
| 事项 | 负责人 | 截止 |
|---|---|---|
| ... | ... | ... |

## 待确认
- ...
```

正文以外不要附加寒暄；纪要本身用中文书写。
