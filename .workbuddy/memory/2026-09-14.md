### WorkBuddy `/stats` 的真实形态（逆向事实，别重查）

**它是 CLI 侧的 TUI 面板 + HTTP API，桌面渲染层没有这个界面。**
证据全在 `docs/WorkBuddy/resources/app.asar.unpacked/cli/dist/codebuddy.js`
（22MB 单包，模块 id 68375 是 StatsService）：

- `GET /api/v1/stats`（跨所有项目、**无任何时间范围参数**）→ `StatsResult`
- `GET /api/v1/stats/session`（当前会话实时）→ `SessionStatsResult`
- 聚合：`StatsServiceImpl.calculateStats()` @11,606,577，
  读 `sessionStore.getAllAcrossProjects()`，逐条消息按 timestamp 归日、
  按 model 归模型、按 toolCall 名归工具
- 公开契约 `StatsResult` = `{totalSessions, totalMessages, totalTokens{input,output},
  totalCost, streakDays, heatmap[{date,count}], modelUsage[{model,count,tokens}],
  toolUsage[{tool,count}]}` @10,670,357；**内部模型远大于它**
- 热力图：`generateHeatmapData(activity, width=56)` → `weeks = clamp(width-8,10,52)`，
  7 行周日起，`getActivityLevel(count,max)` 阈值 .25/.5/.75 分四档，
  终端字符图例字面量 `"Less ░ ▒ ▓ █ More"`
- 面板是 tabbed：`StatsTabbedPanel` → Overview + Models
- **会计口径的关键不对称**：子代理会话从「会话维度」排除（会话数/消息数/热力图/
  工具统计），但**它的 token 用量照算**（模型用量累加在 `isSubagent` 守卫之外）
- legacy 会话（assistant 全无 model 或 "unknown"）整体跳过

### 我们的实现（与它的关键差异）

- 数据源用**会话 JSONL**（`getSessionsDir()`）而非台账：台账文件头明文
  「消息内容与 usage 明细在会话 JSONL 已有，不双写」，且会话 JSONL 覆盖全历史。
  pi 的 `AssistantMessage` 带 `provider`/`model`/`usage`/`timestamp`
  （`开源项目/pi/packages/ai/src/types.ts:415`）
- 子代理判定：会话文件里 `type:"custom" && customType:"subagent_run"`
- token 口径含 cacheRead/cacheWrite（WorkBuddy 的 per-model 只算 input+output，
  长会话里 cacheRead 常是大头，不含会明显失真——有意偏离，已注释）
- 工具多一个 `errors`；**不做耗时**（会话 JSONL 没有工具执行起止时刻，那在台账里）
- 不做 `generateFunFact` 彩蛋；不做时间范围切换（WorkBuddy 接口本身就没有）

## 设置页可配置项调研（打开思路，未动代码）

用户问「设置界面也许要加更多可配置项」。核查后给出三档建议，核心结论：

**瓶颈不在设置页，在配置层。** 每个配置键手写一对专用 IPC
（`getStyle/setStyle`、`getMemoryEnabled/setMemoryEnabled`、`getPermissions/setPermissions`…），
`shared/ipc.ts` 里配置类通道已 20 多个；加一个键要动 6 处文件
（preferences.ts → ipc.ts → preload → bridge → daemon handler → UI）。
而 AGENTS.md §5 承诺的 `config.get(key)` 单一入口**根本不存在** —— 加配置项的前置
是补它（配置注册表 + `config:snapshot`/`config:patch`）。

**WorkBuddy 桌面设置的真身**：`docs/WorkBuddy-reference/extracted/renderer/assets/ui-docs-viewer-C2jT2eXi.js`（14.6MB）
里的 `SettingsNavigation()` @7,234,624，`NAV_GROUPS` @7,239,709、`NAV_ITEMS` @7,240,010：
- 4 组 15 项：general（设置/账户/订阅用量/外观/快捷键）、feature（个性化/记忆/扩展/模型/Claw）、
  dataSecurity（数据管理/安全中心/系统权限 macOnly/软件配置）、about（关于）
- `filteredNavItems` 按 feature flag / 账号类型 / 平台三重过滤显隐；
  「帮助与反馈」连点 5 次进 debug hub（`DEBUG_HUB_EVENT`）
- 遥测事件名暴露了功能点：`DataRetentionPolicySelect`（任务保留期限）、
  `SettingAutoLaunchEnable`（开机自启）、`ProxyModeChange`/`ProxyTestClick`
  （通用→网络代理，none/system/manual）
- CLI 侧 `settings.json` 约 40 键，官方文档 `docs/WorkBuddy/.../cli/dist/web-ui/docs/cn/cli/settings.md`

**pi 已有一整套配置，我们白放着**：`开源项目/pi/packages/coding-agent/src/core/settings-manager.ts`
的 `compaction{enabled, reserveTokens 16384, keepRecentTokens 20000}`、
`retry{enabled, maxRetries 3, baseDelayMs 2000, provider.timeoutMs}`、
`showCacheMissNotices`(默认 false)、`hideThinkingBlock`、`images.blockImages`、
