# 试用功能清单（逐项自验）

> 用法：按顺序过一遍，每项「操作 → 应看到什么」。前置准备见 §0；标注 **\[需配]** 的项要先完成对应配置，标注 **\[需联网]** 的项首次使用要能出网。
> 开发机跑 `npm run dev`；或直接用安装包版（开始菜单「嘉立创Work」）。

## 0. 前置准备（三件事，不做的话后面会卡）

| #   | 准备                                                     | 在哪做                       |
| --- | ------------------------------------------------------ | ------------------------- |
| 0.1 | 配模型：填公司中转（jlc）的 baseUrl + Key + 勾「鉴权走 Authorization 头」 | 设置 → 模型 → 添加自定义服务商 → 测试连通 |
| 0.2 | 配搜索（联网搜索要用）：填一个搜索服务商的 Key                              | 设置 → 通用（联网搜索项）            |

- [x] C2 有思考内容的模型：「深度思考」段可折叠/展开，流式期间有扫光
- [ ] C3 生成中点「停止」→ 立即停下，已生成内容保留；轮头显示「已取消 Ns」+ 正文一行「用户已取消」（**不是**错误卡）；侧栏该任务的转圈立即停；正在生成中的工具卡（write 等）标签变「生成（未完成）」，不会停在「生成中」

- [ ] C8 鼠标移到**你自己的消息**上 → 浮出「重新开始 / 分支出新会话 / 复制」；点「重新开始」→ 回到该轮之前，原文回填输入框，被放弃的后续存成分支会话（有 toast 提示）
- [ ] C9 输入框右侧：上下文占用环（有读数时），点开看分类估算
- [ ] C10 输入卡下方：会话指标条（3 轮、步数、token 等）
- [ ] C11 制造一个错误（比如把 Key 改错）→ 消息流出现**错误卡**（含 runId、重试按钮）→ 改回 Key 点重试 → 恢复正常
- [ ] C12 长对话触发自动压缩，或输入 `/compact` → 出现压缩行，之后继续对话上下文连贯

## D. 权限与沙箱
