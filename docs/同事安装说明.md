# 同事安装说明

面向拿到安装包的同事。装之前花两分钟看完，能省掉大部分卡住的地方。

安装包文件名形如 `JLC-Work-Setup-0.1.0.exe`。

## 一、安装

1. 双击安装包。**不需要管理员权限**（装到当前用户目录）。
2. 安装完成后，桌面和开始菜单会出现「嘉立创Work」。
3. **首次运行会被 Windows 拦一次**：

   > Windows 已保护你的电脑

   点**「更多信息」→「仍要运行」**。

   为什么会拦：安装包没有做代码签名（公司暂时没有代码签名证书），
   Windows 对「没有签名、又从别人那里拿到的 exe」一律先拦。
   这不是病毒提示，是签名缺失的固定表现。以后每个版本第一次跑都会拦一次。

4. 部分国产杀毒软件可能对安装包本身误报，加白名单即可。

安装位置：`%LOCALAPPDATA%\Programs\kamibuddy`（这个目录名是英文小写，属正常）。
卸载器在同一个目录里，叫 `Uninstall JLCWork.exe`。

## 二、装完先做这一步：配模型凭据

**设置 → 模型**，用公司中转：

- `baseUrl`：公司中转地址（问发你安装包的人要，比如 jlc 的地址）
- `API Key`：你自己的 Key
- **勾上「鉴权走 Authorization 头」**（不勾连不上）

## 三、必须知道的三条限制

1. **生成 docx 第一次需要联网**：程序会自动下载 Python 3.12 和几个依赖包，
   大概 1～3 分钟，只做一次。公司网络受限时可能失败，此时找发你安装包的人
   配一下镜像（`UV_INDEX_URL` / `UV_PYTHON_INSTALL_MIRROR`）。
2. **MCP 连接器需要你机器上有 Node.js**：不走这个功能的可以忽略。
3. **不保证离线可用**：模型调用、运行时下载都要网。

## 四、你的数据在哪

| 内容 | 位置 |
| --- | --- |
| 配置、会话历史、记忆、任务记录 | `%USERPROFILE%\.kamibuddy` |
| 生成的文档产物 | `%USERPROFILE%\KamiBuddy` |

**卸载不会删这两处**，重装后历史还在。想彻底清干净就自己手动删这两个目录。

## 五、升级（没有自动更新，要手动）

拿到新版本的 exe 后：

1. **先完全退出应用**（关掉窗口还不够，确认任务栏/托盘里没有残留实例）；
2. 双击新安装包，它会覆盖安装，**数据和配置都保留**。

不退出就装的话，旧版本可能还在跑，出现「装完了但界面没变」。

## 六、常见问题

- **双击图标没反应？** 大概率已经有一个实例在跑（程序是单实例设计），
  去任务栏找一下已有窗口。
- **界面提示「连接已断开」？** 后台服务挂了，重启应用即可。正在跑的任务会中断。
- **要点停止但停不下来？** 先确认是不是正在压缩上下文，等它走完再点。
- **要反馈问题**：请提供**设置 → 诊断**的截图（里面有版本、用量和各组件状态），
  以及你当时在做什么。只发一句「报错了」基本定位不到。

## 七、这一版已知的问题（不用当 bug 报）

- **刷新页面（F5）后，正在等待你确认的权限弹窗会消失**，任务会卡在「正在思考」，
  只能点停止重来。刷新前先确认没有任务在跑。
- **重启应用后，错过的定时任务不会补跑**。
- **专家页的「专家团」子页还是空占位**。
